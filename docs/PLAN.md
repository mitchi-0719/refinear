## 1. プロジェクト概要
アカペラやバンドのグループ練習において、MuseScoreを用いた各パートの音取りは最も練習効率が良い。しかし、現状はPC環境に依存しており、出先やモバイル端末のみで送られてきたファイル（`.mscz`）の内容を確認・再生することが困難である。<br>本プロジェクトでは、専用ソフトを持たないユーザーでも、モバイルのWebブラウザから手軽にMuseScoreファイルを閲覧し、ミキサー操作（特定パートの強調やミュート）などの直感的な操作で音取り練習ができるアプリケーションを構築する。
**（市場の課題と優位性）**<br>スマートフォンでMuseScoreを開けるアプリケーションがここ2週くらいで2つ公開されているが、これらのサービスは音取りで必要になる「特定の音符をタップして発音する」という挙動が実現できていない。そのため、本プロジェクトではその機能を追加した「音取り特化」のWebアプリケーションを作成する。
## 2. 機能要件
### 2.1 MVP
- [ ] **.mscz ファイルの読み込み**: ドラッグやファイル選択で読み込み、ブラウザ内で解析・操作
- [ ] **楽譜描画**: 可能な限りMuseScoreでの表示と同じにしたい
- [ ] **レスポンシブ表示: **
	- 楽譜について
		- 折り返して縦に描画
		- 横方向に描画（端末の縦持ち横持ち両方で横長にスクロールした状態が出来るようにする）
	- アプリケーションについて
		- モバイルで使うことを目的としているため、モバイルのレスポンシブ対応
- [ ] **音源再生: **音源の再生
- [ ] **シーク機能: **
	- 途中（楽譜で指定したところ）から再生
	- 特定の小節から再生
- [ ] **ミキサー機能**: 各パートの音量を調整・ミュート出来る
- [ ] 再生速度変更
	- BPMによる設定
	- ％による設定
- [ ] タップ機能
	- 特定の音符をタップするとその音が聞ける
	- モバイルでタップしにくい問題の解消のためにタップした箇所から最も近い音符を鳴らす等の仕組みも？
- [ ] **PWA対応**: モバイルで簡単に利用でき、オフラインでも利用可能にする
### 2.2 任意要件
- [ ] カーソル機能
	- タップ機能で音符を選択し、そこから上下左右ボタンでカーソル移動が可能
	- 移動した瞬間に移動先の音符の音が鳴る
- [ ] ピアノ機能
	- 開閉可能のピアノが画面の下側に表示
	- ピアノアプリと同様タップしたら音が聞ける
- [ ] セクション機能
	- セクションを楽譜に設定できる
	- 指定したセクションから開始するといったことが出来て、練習の効率化を図る
- [ ] アカウント機能
	- ファイル保存等で利用するためのアカウント
	- メールアドレス, google等でログイン
	- アイコンやアカウント名等の設定
- [ ] ファイル保存・共有
	- オンライン・オフラインでの保存
	- 保存したファイルの共有
	- （後述するテキストでのメモの保存も）
	- 保存の可否は設定可能
- [ ] テキストでのメモ
	- オンラインやデバイス内にデータを保存している場合、メモの追加とかが出来る
	- 手書き文字、テキストボックス入力、マーカー文字 等
	- 共有メモ（共有する全員に表示されるメモ）
	- 個人メモ（自身が利用するメモ）
	- 共有メモの表示非表示
- [ ] PDF出力
	- MuseScoreファイルから楽譜をPDFとしてエクスポート
	- 追記したテキストも含めたエクスポート
- [ ] 音源出力
	- MuseScoreファイルから音源(.wav, .mp3 等)の出力
	- 全体、一部など範囲を絞った音源生成
	- パートのミュート、音量調整などをしたうえでの音源生成
- [ ] セキュリティ・アクセス制御
	- 共有URLへのパスワードロック機能
	- 使用されていない共有URLの自動削除
### 2.3 その他要件
- [ ] 可能な限り軽量なアプリケーションに
	- 個人で気軽に使えるアプリケーションを目指しているので待ち時間や重い処理時間ということを可能な限りなくしたい
## 3. 機能詳細（画面ごと）
### 3.1 モバイル表示
- **トップ画面（アップロード画面）**
	- アプリの概要説明
	- ファイルのアップロード
	- アップロード・変換中のプログレス表示
	- 過去に利用した楽譜の履歴
- **プレイヤー画面（****`/score/[id]`****）**
	- **ヘッダー部**: 
		- ファイル名
		- シークバー（小節指定）
		- テンポ操作UI
		- エクスポート・共有ボタン
	- **楽譜ビューア部**: 
		- SVG/Canvasで描画された楽譜。
		- 再生に合わせてカーソルが移動。
		- 音符タップで発音。
	- **セッティング部:** 開閉ボタンで開閉でき、画面下部から画面の1/3 \~ 2/5程度を占める
		- 開状態
			- 閉状態のバーが一番上にあり、そのしたに選択のタブボタン
			- タブで機能変更
				- スワイプでも変更できても良いかも
			- ミキサー
				- 一番上に全ミュート、全解除ボタン
				- 縦長・横並びで表示
				- 上に楽器名
				- 縦のシークバーで音量調整
				- 下にミュートボタン
				- ソロボタン
			- ピアノ
				- 上にスライダーで音域調整
				- 鍵盤表示
					- 鍵盤を押すと音が鳴る
					- 将来的には、複数同時押しにも対応
		- 閉状態（左から横並び
			- メモボタン
				- ボタンを押したときにメモの設定が出てきてメモがかける
				- メモの設定: 太さ・色・種類・消しゴム・戻る・進む
			- 再生・停止ボタン
			- 開閉ボタン
- **設定画面**
	- 公開している楽譜のリンクコピー、共有
	- 楽譜の公開停止処理
	- 表示
	- 個人設定
### 3.2 デスクトップ表示
- 画面の機能は基本的にモバイルと同じ、配置については必要に応じて変更
## 4. 技術スタック
- **フロントエンド: **TypeScript, Next.js (App Router), Tailwind CSS
- **ファイル解析:** webmscore
	- ユーザーがアップロードした`.mscz`をブラウザ上でWASMを使って解読し、MusicXMLデータを抽出 
- **描画:** OSMD
	- 抽出されたMusicXMLをスマホ幅に合わせてレスポンシブにSVG描画 。
- **再生・操作:** Tone.js / osmd-audio-player
	- 楽譜のMIDI再生、シーク、ミキサー（ミュート/音量調整）、タップ発音 
- **バックエンド:**
	- Storage: 共有用に変換済みのMusicXML（または元の`.mscz`）を保存 
	- Database: 楽曲のメタデータ（タイトル等）とStorageのパスを保存し、一意のIDを発行 
	- Auth: 楽譜保存、共有用のアカウント作成・管理
- **デプロイ:** Vercel
	- Next.jsアプリのホスティング 
- **状態管理**: Zustand
	- 楽譜・音楽関連の状態管理
- **その他**: react-use, prettier, eslint,
